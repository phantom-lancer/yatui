# План правок

Здесь лежит то, что осталось сделать, и что уже проверено. Сделано — отмечаю
галочкой, чтобы не возвращаться дважды. В план входит только работа над
плеером, звуком и его окружением.

## Сделано в ветке `feat/visual-overhaul-performance`

- [x] Визуализатор «Моей волны» — порт шейдера yamusic на CPU, один работник,
  ограниченная очередь кадров, настройка и освобождение ресурсов.
- [x] Графический эквалайзер на 15 полос с кривой и пресетами; классический вид
  на 10 ползунков сохранён, значения мигрируют без сброса.
- [x] Режим экономии ресурсов: визуализатор, снег, RGB и лишние перерисовки
  выключаются, звук и сеть не затрагиваются.
- [x] Гонки конфига: аудиопоток и фоновые работники получают снимки, а не
  читают `config.Current`; `go test -race ./...` в CI.
- [x] Приватные права: конфиг и кэш 0700/0600, права существующих файлов
  исправляются при открытии.
- [x] Лог через буфер, сброс по таймеру и при выходе, без `Sync` на каждую
  строку.
- [x] `--doctor` и `--doctor --json` без секретов, изменений конфига и удаления
  кэша.
- [x] Офлайн-режим `--offline` и переключатель в настройках; каталог
  сохранённых плейлистов, скачивание плейлиста/лайков, проверка целостности,
  удаление `*.part`.
- [x] CI на Linux/Windows/macOS; релиз собирается и проверяется до публикации.
- [x] Документация: README, CHANGELOG, справка `--help`, уведомления и
  `THIRD_PARTY_NOTICES.md`.

## Известные, но не срочные

- Сканирование тегов кэша на старте может быть долгим при большой библиотеке.
- Копирование трека в кэш при догрузке идёт рядом с UI-потоком; на очень
  медленном диске это заметно.
- macOS-бинарник не публикуется: только сборка из исходников.
