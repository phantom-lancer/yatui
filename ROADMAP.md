# План правок

Здесь лежит всё, что нашлось при разборе кода, и в каком порядке это делать.
Сделано — отмечаю галочкой, чтобы не возвращаться дважды.

## v0.10.1 — только баги

Ничего нового, только «стало надёжно».

- [x] Переключение трека больше не вешает интерфейс. Загрузка (обложка, текст,
  `download-info`, сам файл) уходит в горутину, окно продолжает рисоваться и
  реагировать на клавиши. Загрузка со старым номером поколения выбрасывается.
- [x] Вернулся таймаут HTTP. `api.SetupClient` перестал создавать клиент без
  `Timeout`; отдельно клиент для API (15 с) и для аудиопотока (без общего
  таймаута, там свой лимит на чтение). `http.Get` в обложке и текстах заменён
  на этот же клиент — иначе ни прокси, ни сертификаты не работали.
- [x] Ошибки JSON больше не глотаются: битый ответ — это ошибка, а не пустой
  список. Попутно выяснилось, что API присылает одни и те же поля то числом, то
  строкой (id артистов, меток и пинов, id коротких треков в плейлисте,
  `exec-duration-millis`): раньше на этом молча обрывался разбор всего ответа, и
  лайкнутые плейлисты/артисты приходили пустыми. Добавлен `api.ID`, который
  принимает оба вида.
- [x] В Яндекс уходят верные числа: длина трека в `play-audio` и в фидбэке
  радио — секунды, а не миллисекунды (раньше уходило ~240000 секунд).
- [x] Нет паники на треке без альбома и на пустой выдаче радио: `Albums[0]` и
  `Sequence[0]` проверяются на длину.
- [x] При громкости 0 пауза реально ставит трек на паузу (раньше затухание
  выходило из тика до `Pause`).
- [x] Перемотка выравнивает позицию по кадру вниз (`-= pos % 4`), а не сдвигает
  на 1–3 байта: каналы не разъезжаются, щелчка нет.
- [x] Конфиг пишется атомарно (временный файл + `rename`, права 0600) и с
  задержкой: громкость и текст песни больше не переписывают файл на каждое
  нажатие. При выходе — принудительный сброс.
- [x] Кэш пишется атомарно: `.part` + `Commit`, недокачанный файл не выглядит
  как нормальный трек.
- [x] Мелочи: закрывается тело ответа лирики, `log.Stop()` не паникует, тег
  закрывается в `ListTracks` при пропуске файла.

## v0.11.0 — фичи

Крупное:

- Продолжить с места: запоминать плейлист, трек и позицию, восстанавливать при
  запуске.
- Таймер сна (30/60/90 мин, плавное затухание).
- Скачать плейлист или лайки целиком в кэш, офлайн-режим, метка «скачано».
- Проверка обновлений: раз в сутки запрос к GitHub Releases, тост «доступна
  vX.Y.Z».

Небольшое:

- Клавиша mute и процент громкости в тосте; заголовок окна
  `yatui — Трек — Артист`.
- Прокси и горячие клавиши в окне настроек (сейчас только правка YAML).
- Полноэкранный текст песни с прокруткой, а не три строки.
- [x] Last.fm: очередь скробблов, если сети не было.
- «Починить кэш»: проверить размеры файлов, удалить битые.
- [x] В контекстное меню трека — «скачать в кэш».
- В контекстное меню трека — «убрать из кэша».

## Релиз и CI

- `go test -race` в CI: гонки реально есть (`config.Current` читается из
  аудиопотока, `IsBuffered/Progress` без лока).
- Релиз сейчас создаётся до сборок: упавшая сборка оставляет релиз без файлов.
  Собирать артефакты, релиз создавать последним шагом.
- macOS в матрицу релиза + манифесты winget/scoop.
- `--version` есть, но в README не упомянут.

## Известные, но не срочные

- Истёкший токен некуда ввести: 401 на старте даёт «unable to login», вернуться
  на экран входа можно только через `--login`. Надо показывать окно входа при
  `ErrTokenRejected`.
- Аудиопоток ждёт сеть под мьютексом (`stream/bufferedStream.go`) — заикания в
  начале трека на медленной сети.
- Лог делает `Fprintf` + `Sync()` на каждую строку.
- Копирование трека в кэш идёт в UI-потоке.
- Сканирование тегов кэша на старте может быть долгим при большой библиотеке.
