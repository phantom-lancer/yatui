# Пакеты для дистрибутивов

Здесь лежат только те упаковочные файлы, которые можно честно поддерживать без
публикации от имени проекта. Ничего из этого не публикуется автоматически.

## Linux: AUR (`yatui-git`)

`aur/yatui-git/PKGBUILD` собирает текущий `main` из исходников. Это VCS-пакет,
поэтому `sha256sums` содержит `SKIP`: контрольная сумма коммита не имеет смысла,
а тег ещё не выпущен.

```bash
cd packaging/aur/yatui-git
makepkg -si
```

Для публикации в AUR нужно отдельное решение владельца репозитория: имя пакета,
аккаунт AUR и `.SRCINFO`, сгенерированный `makepkg --printsrcinfo`.

## Windows: Scoop и WinGet

Манифесты не добавлены намеренно. И Scoop, и WinGet требуют SHA256 конкретного
опубликованного файла, а релиз с этим кодом ещё не выпущен. Готовый манифест с
выдуманным хэшем хуже отсутствующего: он ломает установку и вводит в
заблуждение.

Когда релиз будет опубликован, манифест Scoop можно собрать так:

```powershell
# после публикации yatui-windows-amd64.exe
$hash = (Get-FileHash .\yatui-windows-amd64.exe -Algorithm SHA256).Hash.ToLower()
# подставить $hash в "hash" манифеста и URL релиза
```

Для WinGet нужен `InstallerSha256` того же файла и PR в
`microsoft/winget-pkgs`. Оба действия выполняются только с согласия владельца
проекта.

## macOS: Homebrew

Бинарник для macOS пока не публикуется (см. README: сборка из исходников).
Формула Homebrew без реального артефакта и его контрольной суммы была бы
фиктивной, поэтому её здесь нет. После появления macOS-сборки формулу можно
сделать на основе релизного tarball с `sha256`.
