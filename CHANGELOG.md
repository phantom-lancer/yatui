# Изменения

Все заметные изменения проекта. Формат — версия, дата, список.

## v0.11.2

- Заголовки разделов настроек получили отдельный тип строки: они пропускаются навигацией, но действие "Конфиг" снова выбирается и показывает путь.


## v0.11.1

**Звук и отзывчивость**
- PCM worker предварительно заполняет буфер перед плавным запуском звука; очередь PCM ограничена примерно 3 секундами, чтобы переживать краткие задержки планировщика без лишнего расхода памяти.
- Декодирование и аудио worker на Windows получают MMCSS Audio scheduling без повышения приоритета всего процесса.
- Перемотка стала неблокирующей: быстрые повторные запросы объединяются, старые PCM-данные и запоздавший EOF не могут испортить новый seek.
- Кэширование трека, включая полную догрузку и запись на диск, вынесено из UI-цикла.
- Предзагрузка следующего трека теперь отключается в настройках и не работает в фоне, если выключена.

**Внешний вид и настройки**
- Снег обновляется с частотой до 30 кадров/с, частицы падают с разной скоростью и дрейфом.
- Гирлянда выбирает свободную строку после изменения размера терминала, а не привязывается к первой строке вывода.
- Настройки разбиты на разделы; счётчик Last.fm показывается в начале значения и не обрезается многоточием.

**Обновления**
- Проверка релиза сначала использует GitHub API, а при недоступности api.github.com переключается на публичную Atom-ленту github.com/releases.atom.
- Для резервного источника собираются ссылки на те же опубликованные бинарники и SHA256SUMS; проверка контрольной суммы перед установкой сохранена.

## v0.11.0

**Стабильность звука**
- Декодирование MP3, измерение громкости, эквалайзер и нормализация вынесены из аудиоколбэка Oto в отдельный ограниченный worker.
- Добавлен PCM-буфер примерно на 3 секунды: аудиочтение не ждёт сеть или декодер, перемотка и завершение трека обрабатываются отдельно.
- Предзагрузка следующего трека в фоне с ограничением 20 МиБ.

**Плеер**
- В настройках появилась ручная проверка обновлений. До нажатия кнопки приложение не обращается к GitHub.
- Кнопка установки появляется только при наличии новой версии. Бинарник и SHA256 проверяются до замены; установщик сохраняет резервную копию и умеет откатиться.
- Last.fm показывает число скробблов, ожидающих отправки.
- Добавлена зимняя тема с настройкой количества снега и плавно меняющей яркость гирляндой. При выключенных эффектах таймер анимации не запускается.

Таймер сна и мобильная версия не добавлялись. Существующее оформление терминала и его прозрачность не менялись.

**Яндекс Музыка**
- дизлайк радио отправляет отдельное событие `dislike` с ID трека, временем
  прослушивания и данными сессии; обычный `skip` больше не дублирует его;
- добавление и снятие лайка выполняются в фоне, локальное состояние меняется
  только после успешного ответа API.

**Производительность**
- убран постоянный тикер громкости: плавное изменение запускается только на
  время fade и завершается автоматически;
- Discord RPC больше не опрашивается, когда отключён;
- отложенная отрисовка действительно объединяет частые события мыши и прогресса;
  нажатия, отпускания и клавиши остаются мгновенными;
- текущая строка синхронизированного текста ищется бинарно, стили субтитров
  и базовый стиль обрезки строк переиспользуются.

**Внешний вид**
- сохранены существующие темы, прозрачный фон терминала, цвета, геометрия и
  настройки; новые фоны и подложки не добавлялись.

## v0.10.1

**Надёжность**
- переключение трека больше не замораживает интерфейс: обложка, текст песни и
  сам файл загружаются в фоне, а окно продолжает отвечать на клавиши и мышь;
- вернулся таймаут HTTP-запросов к API (15 секунд), у аудиопотока остался свой
  лимит на чтение; обложка и тексты песен идут через тот же клиент, так что
  прокси и свои сертификаты работают и для них;
- битый ответ API теперь ошибка, а не пустой список;
- конфиг пишется атомарно и с задержкой: громкость и текст песни больше не
  переписывают файл на каждое нажатие, при выходе изменения сохраняются;
- кэш пишется через временный файл: недокачанный трек не выглядит нормальным;
- приложение не падает на треке без альбома и на пустой выдаче радио.

**Плеер**
- исправлены числа, которые уходили в Яндекс: длина трека и прослушанное
  время теперь в секундах (раньше — в миллисекундах);
- на нулевой громкости пауза действительно ставит трек на паузу;
- после перемотки позиция выравнивается по кадру вниз, а не сдвигается на
  1–3 байта: каналы не разъезжаются и нет щелчка.

**Мелочи**
- закрывается тело ответа с текстом песни;
- `log.Stop()` не падает, если лог не открылся;
- список кэша не теряет открытый тег при пропуске файла.

## v0.10.0

**Вход**
- вход через браузер по коду устройства: кнопка в окне входа открывает
  `ya.ru/device`, код уже в буфере обмена, токен подхватывается сам;
- токен проверяется через API до сохранения, поэтому неудачный вход больше не
  затирает рабочий токен;
- `yatui --login` открывает окно входа, не стирая сохранённый токен;
- кнопка входа подсвечивается под мышью.

**Плеер**
- эквалайзер сохраняется между запусками: настройки применяются сразу при
  старте, а окно показывает сохранённое состояние;
- исправлены режимы повтора;
- каталог конфига не пересоздаётся при обновлении.

**Discord RPC**
- компактная карточка по умолчанию: артист, без альбома, версии, иконки,
  кнопок и подписи; скрывается через 5 минут после паузы (старые настройки по
  умолчанию переносятся один раз, изменённые вручную не трогаются).

**Сборка**
- в релизах больше нет архива `vendor` и файлов без платформы в имени:
  `yatui-linux-amd64`, `yatui-linux-amd64-nomedia`, `yatui-windows-amd64.exe`,
  `yatui-windows-amd64-nomedia.exe` и `SHA256SUMS`;
- обновлены зависимости.
